## **必须**遵守下面的规范文件格式（没有则创建）
.spec                               # 当前项目下的规范文件的根目录
├── spec.md                         # 当前项目**必须遵守**的规范文件每次都需要读取
├── rules.md                        # 当前项目**必须遵守**的规则约束
├── xxxx                            # 对应的功能目录
│   ├── .archive                    # 功能归档的需求目录（已实现）
│   ├── spec.md                     # 功能的规范文件
│   └── subxxxx                     # 当前功能的需求目录
│       ├── design.md               # 当前需求的设计文件
│       └── changes                 # 当前需求的更改目录
│           ├── tasks.md            # 当前需求的实施任务清单
│           └── xxxxx.xx            # 当前需求的实施实施时的其他产物比如数据的变更sql、对外sdk、需外部更改的配置等
├── xxxx1                           # 对应的另外的功能目录
│   └── spec.md                     # 功能的规范文件
└── xxxx2                           # 对应的另外的功能目录
    └── spec.md                     # 功能的规范文件
