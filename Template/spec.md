## 数据流向图
{{举例：用户请求 → Controller层 → Service层 → Infra层 → 数据库  
        ↑          ↑         ↑        ↑  
        |          |         |        |  
        ↓          ↓         ↓        ↓  
        用户响应 ← Controller层 ← Service层 ← Infra层 ← 数据库 

- 用户发送HTTP请求到Controller层  
- Controller层接收请求参数，进行基本校验  
- Controller层将VO转换为DTO，调用Service层  
- Service层实现业务逻辑，调用Infra层  
- Infra层执行数据库操作，返回Entity  
- Service层将Entity转换为DTO，返回给Controller层  
- Controller层将DTO转换为VO，返回给用户  }}
